# ABAC Compliance Hub

A self-contained reference app for anti-bribery and anti-corruption (ABAC) laws, policies, and procedures.

## Sections

- **Laws** — summaries of key ABAC statutes and treaties (FCPA, UK Bribery Act, OECD Convention, UNCAC, Sapin II, Brazil's Clean Company Act, India's PCA, Canada's CFPOA, Australia's foreign bribery offense).
- **Policy** — a full model company Anti-Bribery and Anti-Corruption policy (gifts, facilitation payments, third parties, political/charitable contributions, reporting, etc.).
- **Procedures** — step-by-step operational workflows (third-party due diligence, gift approvals, facilitation payment response, M&A diligence, incident reporting, training, monitoring/audit).
- **Red Flags** — realistic bribery/corruption warning-sign scenarios grouped by category.
- **FAQ** — quick answers to common employee questions.

All content is searchable from the header search box.

## Development

```bash
npm install
npm run dev      # start dev server
npm run build    # production build to dist/
npm run preview  # preview the production build
```

Built with React, TypeScript, Vite, Tailwind CSS, and React Router. No backend — all content is static and client-side.

This app is a general reference tool and educational resource. It is not legal advice; consult qualified counsel for guidance specific to your organization and jurisdiction.
